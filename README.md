
This project focuses on developing a customer segmentation for a financial institution (SBI Life Insurance) to enable targeted recommendations for products like saving plans, loans, and wealth management.

The analysis is based on a dataset summarizing the usage behavior of approximately 9,000 active credit card holders over a 6-month period. The dataset includes 18 behavioral variables at the customer level.

The key steps involved in this project are:

1) Data Loading and Exploration: Loading the credit card customer data and exploring its basic characteristics (e.g., shape, data types, missing values).
2) Data Cleaning and Preprocessing: Handling missing values and any necessary data transformations.
3) Customer Segmentation: Applying clustering techniques to segment customers based on their credit card usage behavior.
4) Analysis and Recommendations: Analyzing the characteristics of each customer segment to derive insights and provide targeted product recommendations.
